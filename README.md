## Deployment

Deploy as a static site on Vercel: Framework Preset **Other**, no build command, output directory **.**. No package installation is needed. Keep `index.html`, `style.css` and `script.js` at the root.

Enable Web Analytics for this Vercel project, deploy, then verify `/_vercel/insights/script.js` and recorded visits in the dashboard. The page includes exactly one analytics script and initialization queue.
